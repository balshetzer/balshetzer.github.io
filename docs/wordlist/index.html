Settings

The app reads and writes the private repo through the GitHub API with a token kept only on this device.

How to make the token
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: only balshetzer/yiddish-cryptics.
  3. Permissions: Contents read and write, Actions read and write.
  4. Pick an expiry you can live with, then paste the token above.
